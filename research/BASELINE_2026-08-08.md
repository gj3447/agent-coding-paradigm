## Findings retained

### Functional and logic boundary

- Algebraic effect work supports exposing effects in types/contracts and separating calculations from handlers: [Koka effect types](https://arxiv.org/abs/1406.2061), [effect handlers](https://arxiv.org/abs/1312.1399).
- Recursive logic requires explicit monotonicity and fixpoint semantics rather than rule-order accident: [Datafun](https://www.cl.cam.ac.uk/~nk480/datafun.pdf), [Semi-naive Datafun](https://www.cl.cam.ac.uk/~nk480/seminaive-datafun.pdf), [CALM](https://arxiv.org/abs/1012.2858).
- Unknown and conflicting evidence are distinct semantic states: [Well-Founded Semantics](https://doi.org/10.1145/116825.116838), [four-valued bilattices](https://www2.mta.ac.il/~oarieli/Papers/Proofs-PDF/jai_1998_p.pdf).
- Retraction requires support/derivation accounting: [Incremental View Maintenance](https://doi.org/10.1145/170036.170066), [provenance semirings](https://www.cs.ucdavis.edu/~green/papers/pods07.pdf).

### Logic/reactive seam

- Signed, versioned changes form a plausible narrow waist between logical derivation and reactive propagation: [Differential Dataflow](https://www.cidrdb.org/cidr2013/Papers/CIDR13_Paper111.pdf), [DBSP](https://www.vldb.org/pvldb/vol16/p1601-budiu.pdf).
- Stable completion in concurrent dataflow requires progress information such as logical time/frontiers, not a momentarily empty queue: [Naiad](https://www.microsoft.com/en-us/research/wp-content/uploads/2013/11/naiad_sosp2013.pdf), [Dataflow Model](https://research.google.com/pubs/archive/43864.pdf).
- Reactive interoperability requires bounded demand and non-blocking backpressure at asynchronous boundaries: [Reactive Streams](https://www.reactive-streams.org/).

### Typed graph engineering

- RDF datasets, SHACL validation, PROV-O provenance, action/CAS identity, dependency graphs, and sampled traces solve different problems and must not be flattened: [RDF 1.2 Concepts](https://www.w3.org/TR/rdf12-concepts/), [SHACL](https://www.w3.org/TR/shacl/), [PROV-O](https://www.w3.org/TR/prov-o/), [Remote Execution API](https://github.com/bazelbuild/remote-apis/blob/main/build/bazel/remote/execution/v2/remote_execution.proto), [OpenTelemetry Trace API](https://opentelemetry.io/docs/specs/otel/trace/api/).
- Canonical bytes, isomorphism, semantic equivalence, resolved composition equivalence, and behavioral equivalence are separate claims: [RDF Dataset Canonicalization](https://www.w3.org/TR/rdf-canon/).
- Dependency-driven incremental recomputation depends on complete declared inputs: [Skyframe](https://bazel.build/reference/skyframe), [Salsa algorithm](https://salsa-rs.github.io/salsa/reference/algorithm.html).

### Durable loop and harness

- Durable workflow systems separate replayable control from external activities and require idempotency/reconciliation at effect boundaries: [Temporal workflow execution](https://docs.temporal.io/workflow-execution), [Temporal activity definition](https://docs.temporal.io/activity-definition).
- Checkpoints and interrupts do not imply exactly-once effects; resumed work may re-execute: [LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence), [LangGraph interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts).
- A model/tool loop can stop on final output or a turn bound, but that is not proof that an external task succeeded: [OpenAI Agents SDK running agents](https://openai.github.io/openai-agents-python/running_agents/).
- CloudEvents standardizes an event envelope and duplicate identity hints, not workflow order, causation, authorization, or exactly-once execution: [CloudEvents specification](https://github.com/cloudevents/spec/blob/main/cloudevents/spec.md).

## Synthesis boundary

No cited source defines the FLR-H architecture as a whole. The whole is a local synthesis. Constituent-source maturity cannot be multiplied into proof that the synthesis is correct, novel, efficient, or production-ready.

## Open research questions

1. Where exactly should policy/authority rules stop in L and capability enforcement begin in H?
2. Should an explicit contradiction block an effect by default or yield scoped abstention?
3. When can rule migration use differential migration instead of clean recomputation?
4. Who ratifies permissible production/harness adapter substitutions, and with what evidence?
5. What budgets prevent adversarial graph canonicalization and recursive fixpoint blowups?
6. Which language best expresses the v0 types and fault tests without prematurely fixing the implementation architecture?
7. After mechanics close, which held-out coding tasks and long-horizon outcomes can test comparative efficacy fairly?
